SKIN POWERS v1.3.0 FIX2 - MAVEN İNDİRME DÜZELTMESİ
===================================================

Bu küçük paket yalnızca şu dosyayı değiştirir:
.github/workflows/build.yml

UYGULAMA
1. ZIP dosyasına sağ tıkla ve "Tümünü Ayıkla" seç.
2. Ayıklanan klasörün içindeki .github klasörünü kopyala.
3. GitHub Desktop'ta Repository > Show in Explorer seç.
4. Açılan ana proje klasörüne .github klasörünü yapıştır.
5. "Hedefteki dosyaları değiştir" seç.
6. GitHub Desktop Summary alanına şunu yaz:
   1.3.0 FIX2 Maven indirme yeniden denemesi
7. Commit to main ve ardından Push origin yap.

NEYİ DÜZELTİR?
- Mod Menu Maven indirmesi yarıda kesilirse derlemeyi otomatik yeniden dener.
- İkinci ve üçüncü denemeden önce yarım kalmış Mod Menu önbelleğini temizler.
- Yeniden indirmeyi --refresh-dependencies ile zorlar.
- Java oyun kodlarına ve güçlere dokunmaz.

NOT
İlk hata Java kodundan kaynaklanmıyordu. Terraformers Maven sunucusundan
modmenu-18.0.0.jar indirilirken bağlantı yarıda kesilmişti.
